## 🚀 Projeto em destaque

### 💧 [ONG Água Pura — Site institucional](https://github.com/italoleal567/agua_pura)

Site responsivo desenvolvido em grupo como projeto acadêmico, simulando a presença digital de uma ONG fictícia. O projeto reúne páginas institucionais, navegação, interação e validação de formulário.

**Tecnologias utilizadas:** HTML5, CSS3 e JavaScript.

> Projeto educacional: a ONG é fictícia e o formulário não envia nem armazena dados.
